# SUPER-AI-9JA — Foundation Documentation

Version: 1.0.0
Status: Foundation baseline
Scope: Nigeria only

## Mission
Build an accessible, credible, Nigeria-first AI learning platform that helps
learners develop practical AI skills and apply them to real work.

## Required languages
- English (`en`)
- Nigerian Pidgin (`pcm`, provisional; verify library/provider support)
- Yorùbá (`yo`)
- Hausa (`ha`)
- Igbo (`ig`)

UI language, course-content language, and tutor-response language are separate
concepts and must not be conflated.
